# Event Management System

This project is a robust backend application developed as part of the Backend Development Diploma at **Cairo Coding School**.

It serves as a practical implementation of backend engineering principles, demonstrating proficiency in:

*   **C# & .NET Framework / .NET Core**
*   **Object-Oriented Programming (OOP)** and Clean Architecture concepts
*   **LINQ** for data manipulation and complex querying
*   **ADO.NET** for direct and optimized database connectivity
*   **Repository Pattern & Dependency Injection** to decouple data access from business logic (supporting both SQL and In-Memory providers)
*   **Data Transfer Objects (DTOs)** for efficient data shaping and presentation
*   **SQL Server** database design and relational mapping

The system is designed to manage events, attendees, and related operations efficiently, showcasing the ability to build scalable and maintainable backend solutions.
